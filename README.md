# Arduino Smart Fan
## Project Overview
This project involves developing an Arduino-based fan system that uses temperature and motion sensors to control fan operation.

## Objectives
- Measure temperature using a TMP36 sensor.
- Detect motion using a PIR sensor.
- Control fan speed using PWM.
- Use an L293D motor driver to control the DC fan.
- Indicate operating conditions using LEDs.

## Components
- Arduino Uno
- TMP36 temperature sensor
- PIR motion sensor
- L293D motor driver
- DC fan
- LEDs and resistors
- Power supply and connecting wires

## How it works
The Arduino reads temperature and motion sensor inputs and uses programmed conditions to control the fan and LEDs. PWM can be used to adjust the fan speed.
